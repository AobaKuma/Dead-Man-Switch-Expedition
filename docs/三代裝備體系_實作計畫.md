# 三代裝備體系（老資歷／中登／小登）

狀態：P0–P3 實作並通過遊戲內驗收（2026-10-21）；待美術與舊存檔實測。研究節點之後已重整，以[科技樹文件](導彈與雷達科技重整_執行計畫.md)為準；現行數值、成本以 `1.7/Defs` 為準。物品文案見[物品介紹](三代裝備體系_物品介紹.md)。原始完整計畫（含逐項成本、平台數值表、需求對照）在 `docs/_archive/`。

## 1. 三組定位

| 組 | 定位 | 平台特徵 | 飛彈 |
|---|---|---|---|
| 老資歷 T0 | 二戰古董：多要手操、安全性差，但便宜、不需電子工業 | 手操、免電或低電、塔式發射有衝擊波與火焰 | V1、V2、萊茵女兒 |
| 中登 T1 | 冷戰貨：可靠可量產，堆量時佔地大 | 多數全自動、吃電、1x3～4x4 | 白蟻、刺針、小牛、SA-19、白蛉、圓點U |
| 小登 T2 | 現代：昂貴、高度電子化、極耗電 | 垂直發射、高通道、高單價 | 麻雀、地獄火、鷹擊、戰斧、民兵3 |

四條設計軸：
1. **人力**：T0 多數 `CompMannable`；T1 只有防空導彈發射架需要人；T2 全自動。
2. **電力**：T0 聲學雷達 0 W、其餘 ≤1,200；T1 200–2,500；T2 相控陣 9,000、千禧年 3,000。
3. **通道**（全陣營一本帳 `BVRChannelLedger`）：聲學 0、老式火控 1、野戰防空砲 2、火控雷達 4、相控陣 24。
4. **攔截品質** `interceptHitFactor`（乘在火控命中率上）：萊茵女兒 0.6、刺針 0.85、SA-19／地獄火／通用攔截彈 1.0、麻雀 1.25。

**配方材料分代**（2026-10-27）：T0 鋼＋工業零件；T1 鎢鋼（`Tungsteel`）＋沖壓零件（`ComponentStamped`）；T2 鉭合金（70%）＋石墨烯（30%）＋高級零件（`ComponentSpacer`）；化學燃料保留為推進劑。`.source/Tools/tier_missile_costs.py` 換算時保持市值不變。預設零件材料折算進物品配方。平台與零件本身配方未改。

## 3. 機制（C#）

| 項 | 內容 |
|---|---|
| 相容性 | 平台能裝什麼**只看建築 storage filter**（`MissileTaxonomy.PlatformAccepts` 原本無呼叫端）。`MissileRackExtension.extraSizeClasses` 供分級與檢查器；`check_missile_content.py` 第 8 條驗證 filter × 分級 |
| 用途過濾 | `MissileRoleExtension.CanIntercept`：攔截器原本會把容器內任何導彈當攔截彈射掉 |
| 固定構型物品 | `MissileItemExtension.body`；`ConfigFor(Thing)`：`CompMissileConfig` → 擴充彈體 → null；Rail 的 `BuildFiringConfig` 先讀它再退回平台 `missileBody` |
| 內建導引 | `builtInGuidance` 只決定落點、不提供導引能力；新增 `MissileBodyDef.builtInTerminalGuidance`（白蟻追船） |
| 研究門檻 | 發射架換彈體原本不檢查研究；`MissileBodyDef.researchPrerequisites`／`ResearchSatisfied`，ITab 鎖定未研究彈體（上帝模式例外）；熱核彈頭補門檻 |
| 攔截係數 | `interceptHitFactor` 在 `MapComponent_BVRCombat` 與 `WorldComponent_BVRNetwork` 乘入命中率 |
| 塔式衝擊波 | `CompLaunchBackblast`（`TryLaunchRound`／`FireInterceptor` 成功後）：半徑 3.5、Flame 18、點燃 0.8、震懾 60、不傷建築 |
| 塔架頂層 | `CompMissileBodyRenderer.overlay`，未裝彈也畫 |
| 手操 | `CompBVRDevice.Active` 把沒人操作算不可運作；`Building_TurretGun.Tick` 在有 Mannable 且無人時不射擊；有攔截 Comp 時 `CompMannableMissileLauncher` 改派 `DMSE_ManMissileLauncher`（操作者自己搬彈） |
| 單兵具 | `ManPortableSAM.cs`：`CompManPortableSAM` 繼承 `CompApparelReloadable`（2 發、刺針）；`Patch_ManPortableSAMReload` 在 `ReloadFrom` 前後記錄每枚 `MissileConfig`（LIFO）；Gizmo 列出本地圖 40 格內、剩餘 ≤2,400 ticks、未被占用的 BVR 目標，`DMSE_FireManPortableSAM` 瞄準 90 ticks 後發射；命中率用自帶火控參數（0.6）× 0.85＋戰鬥部加成；**不占通道**，冷卻 300；對地用原版 `Verb_LaunchProjectile` |
| NPC 陣地 | 抽象防空 `channels` 2 → 4（因應相控陣 24 通道） |

## 4. 決策

- D-1 相控陣 24 通道不加權重，觀察一輪。
- D-2 相控陣留在 Aerospace（當時 Strategic 隱藏前置 Aerospace，移過去只會更晚）。
- D-3 backblast 不傷建築。D-4 Flak 37 可打地面。D-5 保留 Scorer。
- D-6 戰斧放 Strategic。D-7 刺針、麻雀純攔截；兩用留給 SA-19、地獄火。D-8 單兵具不占通道。

## 5. 存檔與命名

- **ThingDef 名稱不能以數字結尾**（載入報 "ends with a numerical digit"）：`DMSE_LightMissile` → `DMSE_Missile_Grison`、V1 → `DMSE_Missile_LegacyLoiter`、Flak 37 → `DMSE_Turret_LegacyFlak`。檢查器第 9 條會擋。舊存檔的「輕型導彈」會消失（1.7 開發版接受）。
- 舊白蛉物品仍指向 `DMSE_MissileBody_Cruise`，照常能飛。白蟻改導引讀檔即生效。容量、通道變更讀檔即生效。
- 研究延後會讓舊存檔暫時失去配方，已建成的不受影響。
- 未驗證：聲學雷達移除 `CompPowerTrader` 後舊檔是否警告（K-T7 未做）。
