# 三代裝備：物品文本規範

遊戲內 `label`／`description` 以 Def（英文）與 `DefInjected`（繁中、簡中）為準：英文在 `1.7/Defs/**.xml`，繁中在 `1.7/Languages/ChineseTraditional (繁體中文)/DefInjected/<Type>/<檔名>.xml`，簡中由繁中轉換。2026-10-21 已套用 32 條三語文本；2026-10-28 雷達、彈體與發射建築依 §1 全部改寫。

各型號的長篇設定稿（舊文風、含真實型號比喻）已移到 `docs/_archive/三代裝備體系_物品介紹.md`，只當設定參考；V2、圓點U、民兵3 沒有物品型態，資訊卡顯示彈體描述，長稿保留給日後的「彈體百科」。Def 名冊見[三代裝備體系](三代裝備體系_實作計畫.md) §2。

## 1. 風格規範（RimWorld 原版文風）

1. **開頭**：第一句說它是什麼。英文 `A/An ...`，中文「一種／一座／一套……」。
2. **短句**：每句一件事，用句號斷開，不用分號串長句。整段 2–4 句。
3. **順序**：是什麼 → 能做什麼 → 主要取捨（慢、貴、耗電、不準）。
4. **玩法說明另起一段**（英文 `\n\n`）：裝配槽、需要操作員、需要電力、不能建在重力船上、由火控網自動發射等，用陳述句（「Requires an operator.」「需要操作員。」）。
5. **不用真實型號**：不寫 V-2、地獄火、戰斧、民兵三型，也不寫「XX 級」比喻。標籤用功能名。
6. **不寫精確數值**：資訊卡數據欄已顯示射程、耗電、通道；描述用「數枚」「二十多枚」。
7. **語氣**：平實具體，可有一點冷幽默；不堆比喻、不寫年代旁白。不用破折號，不提後勤人員、車輛、搬運器具。
8. **英文美式拼寫**（defense、fueled）。

## 2. 套用規則

- `DefInjected` Type 資料夾：`ThingDef`、`DMSE.MissileBodyDef`；新平台在 `ThingDef/DMSE_GenerationPlatforms.xml`、`DMSE_GenerationTurrets.xml`、`DMSE_SamLauncher.xml`。
- `\n` 只用於真正的分段。標籤不含型號。`label` 與 `descriptionHyperlinks` 不互相矛盾。
- `python .source/Tools/check_missile_content.py .` 第 7 條檢查彈體、固定構型物品、發射平台的三語文本都存在。
