## 0. 素材依據

### 0.1 參考圖六幕

| 幕 | 畫面 | 本實作的對應 |
|---|---|---|
| 1 | 彈體垂直爬升、地面白煙柱 | 升空段：`rotationCurve` 幾乎 0、煙柱筆直（§2 幕 1） |
| 2 | 彈頭附近一閃 | 第一次側推點放的第一 tick（3 團白煙＋火焰） |
| 3 | 彈體開始轉向、側面噴出小火焰 | 側推點放（`turnJetPulse*`，§2 幕 3） |
| 4 | 接近水平、反方向的小火焰煞停 | 反推（`IsBraking` → `turnJetBrakeScale`，§2 幕 4） |
| 5 | 彈頭前方的縱向推進器向前脫離 | `Jettison()` 的 pod（§2 幕 5） |
| 6 | 尾焰變成一大團白橘色 | `mainThrust` / `mainPlumeScale`（§2 幕 6） |

看得到的重點，直接影響實作：

1. 冷彈射離筒，兩顆小助推讓彈體自轉。
2. **六顆小型固體助推一顆接一顆點火**（畫面標 1–6），不是一路長燃；每一下都留下一團白煙。
3. 再一顆助推把彈體推上目標方位。
4. **彈頭那一截帶噴嘴的轉向段分離**。
5. 主發動機點火、加速離場；旁白說「整個過程要在 2 秒內完成」。

換算：2 秒 ≈ 120 tick，所以「點放」是正確的形狀；本實作在 120° 極端迴轉只用 55 tick，比實彈還快。
遊戲裡 Oniks 是熱射（不是筒射），因此第 1 幕沒有筒內彈射，直接從點火煙柱開始。

## 1. 名詞與座標

- **彈體畫面中心** `center`＝`LaunchDrawPos`（貼圖 512²、`drawSize` 3.71，以中心對齊）。
- **前** `f`＝`HeadingVector(LaunchRotation)`；**側** `side = (f.z, 0, −f.x)`（右手側）。
- **噴口** `Nozzle`＝`center − f × NozzleOffset`，`NozzleOffset = −offsetY`（Oniks 1.81 格）。
- 貼圖量測：512 px、1 px ＝ 3.71 / 512 ＝ **0.00725 格**。

| 貼圖特徵 | 像素 y | 距中心 | 用途 |
|---|---|---|---|
| 鼻尖 | 2 | **+1.85 格** | 機頭 RCS 噴嘴、轉向段位置 |
| 助推器底 | 506 | **−1.81 格** | 機尾 RCS 噴嘴、主尾焰起點 |
| `skyFaller_incoming` 尾端 | 394 | −1.00 格 | 分離後尾焰（`separatedOffsetY` −0.95） |

## 2. 六幕規格

> 時間軸一律「自**機頭真的開始轉**的那個 tick（`turnStartT`）起算」。`turnStartTick 48` 只是讓狀態先就緒，
> 升空段角速度是 0，太早計時會讓上限把轉向砍一半。

### 幕 1：垂直爬升（`turnStartT` 之前）

| 項目 | 規格 |
|---|---|
| 觸發 | 點火後到交接（`ascentHandoff 0.3` 或位移 16 格）→ 機頭幾乎不轉 |
| 畫面 | 彈體幾乎垂直：Oniks `rotationCurve` (0,0)(0.35,−3)(0.65,−2)(1,0)；煙柱一柱到底 |
| 不該有 | 任何 RCS 火焰（`|rotRate| < turnJetRate`） |
| 幾何 | 主尾焰從助推器底（−1.81 格）噴出，不是從貼圖內 |

### 幕 2：開始轉向（`turnStartT`）

| 項目 | 規格 |
|---|---|
| 觸發 | `t ≥ turnStartTick(48)` 或 `|rotRate| ≥ turnJetRate(0.6)`；`turnStartT` 取 `|rotRate| ≥ 0.15` 的第一個 tick |
| 畫面 | 第一下側推＝火焰＋3 團白煙（幕 2 的「一閃」） |

### 幕 3：側推點放

| 項目 | 規格 |
|---|---|
| 條件 | `|rotRate| ≥ turnJetRate`（真正在轉才噴） |
| 節奏 | 噴 `turnJetPulseTicks = 3` tick、停 `turnJetPulseGapTicks = 8` tick（週期 11） |
| 次數 | 最多 `turnJetPulses = 6` 下（對齊影片六顆助推） |
| 方向 | `turnCouple = sign(rotRate)`；**機頭**排氣往 `−turnCouple × side`、**機尾**往 `+turnCouple × side`（一對力偶） |
| 火焰 | 長 `turnJetLength 2.4 × strength × effectScale`、寬 `turnJetWidth 0.8 × …` |
| 煙 | 每 tick 前後各 `turnJetPuffs = 2` 顆；每下第一 tick 再補 `turnJetPulsePuffs = 3` 顆／嘴 |

### 幕 4：反推止轉

| 項目 | 規格 |
|---|---|
| 條件 | 已經轉過（`hasTurned`）且 `IsBraking(rotRate, rotAccel)`：角速度與角加速度反向，且 `|rotRate| < turnJetRate` |
| 畫面 | 換另一側噴：`turnCouple = −sign(rotRate)`；強度 `0.55 × turnJetBrakeScale(0.75)` ≈ 0.41（火焰約 1 格） |
| 收尾 | 記下 `brakeAt`，固定再等 `turnBrakeTicks = 5` tick 就進入幕 5（欠阻尼煞停是一段一段的，不能累計 tick） |

### 幕 5：拋棄轉向推進器

| 項目 | 規格 |
|---|---|
| 觸發（任一） | ① 6 下點放用完；② 真的煞停（`turnStartT` 後 ≥ `turnMinTicks 8`、`brakeAt` 後 ≥ 5 tick）且已噴 ≥ 3 下；③ `turnMaxTicks 90` 安全上限 |
| 位置 | `podPos = center + f × turnPodOffset(2.45)`：鼻尖 1.85 再留 0.05 格縫；pod 大小 1.1 × 0.55 |
| 速度 | `podVel = 彈體本 tick 位移 + f × turnPodEjectSpeed(0.16) × effectScale`（往前甩） |
| 後續 | 每 tick `podVel ×= 0.975`、`podPos += podVel`、`podRot += podSpin`（±10°/tick × 0.6–1.4 隨機）；`turnPodLifeTicks 100` 後移除 |
| 貼圖 | `turnPodTexPath = Things/Effects/MissileFx/OniksNose`：直接從 `skyFaller.png` 裁 y 2–206（含鼻錐暗色導引頭環），所以掉下來的就是它自己的頭 |
| 一瞬間 | 閃光 `DMSE_InterceptFlash`，大小 `0.35 × ignitionFlash × effectScale`（別太大，會被讀成彈頭爆炸）；再 8 顆白煙（forward bias 0.6） |

### 幕 6：主推力全開

| 項目 | 規格 |
|---|---|
| 觸發 | 拋棄後的同一 tick 起算 |
| 推力 | `mainBlend = Clamp01((t − jettisonT) / 12)`；`thrust = Lerp(thrust, max(thrust, mainThrust 1), mainBlend)`，**在 `burnDurationTicks` 裁切之前**（燒完的彈體不會被主推力救回來） |
| 尾焰 | 長 `× (1 + 0.3 × main)`、寬 `× (1 + 0.55 × main)`、`mainPlumeScale 1.3`；顏色 `Lerp(flameColor, mainFlameColor(1, 0.82, 0.55), 0.7 × main)` |
| 煙 | 推力變大→`EmitSmoke` 每 tick 的顆數自然變多、更大更快 |

## 3. 狀態機（`LaunchFxEmitter.UpdateTurn`）

```text
if !turnJets                 → 不做任何轉向特效
TickPod()                    // 已拋棄的 pod 照樣推進
if !ignited || jettisoned    → strength = 0; return

rate = |rotRate|             // rotRate = DeltaAngle(prevRot, curRot)
if !turnActive:
    forced = turnStartTick > 0 && t >= turnStartTick
    if !forced && rate < turnJetRate → return          // 還沒開始轉
    turnActive = true; brakeAt = -1; lastPulseIndex = -1; pulsesFired = 0

if turnStartT < 0 && rate >= 0.15 → turnStartT = t    // 真的開始轉才計時
if rate >= turnJetRate            → hasTurned = true
braking = hasTurned && IsBraking(rotRate, rotAccel)
if braking && rate < turnJetRate && brakeAt < 0 → brakeAt = t

if rate >= turnJetRate:                     // 幕 3
    strength = 1; couple = sign(rotRate)
    phase = (t − turnStartT) % 11
    if phase >= 3: strength = 0             // 停 8 tick
    elif new pulse: pulsesFired++; pulseJustStarted = true
elif braking && rate > 0.02:                // 幕 4
    strength = 0.55 × turnJetBrakeScale; couple = −sign(rotRate)
else: strength = 0

if pulsesFired ≥ 6 || (煞停 && pulsesFired ≥ 3) || t − turnStartT ≥ 90:
    Jettison(); return                      // 幕 5 + 幕 6
draw smoke (2/嘴，每下第一 tick +3/嘴)
```

公開診斷（V9 用）：`TurnActive`、`TurnJetAim`（＝目前 strength，>0 代表有火）、`TurnRate`、`MainThrustBlend`、`Jettisoned`、`PodAge`、`PodPos`。

## 5. 與飛行的交界

1. **機頭角速度是唯一輸入**：`rotRate` 就是 `LaunchRotation` 的逐 tick 差分，所以大角度、小角度、左右轉、過轉回修全都自動對得上，不必知道發射方位。
2. **航向與機頭分開**（`courseTurnsIndependently`，只有 Oniks 開）：
   - 航向 `motion` 用 `CourseTurnStep`（比例控制＋角加速度限制、不超過剩餘誤差）**單調**轉過去，煙跡是一條乾淨的弧，不會折返。
   - 機頭 `nose` 仍用欠阻尼 `TurnCorrectionStep`，保留過轉／回正給側推與反推看。
   - `TurnBlend < 0.98`（還沒對準）時速度上限 `speed0 × 1.02`，**對準後才由巡航速度曲線加速**＝影片的「轉完才點主助推」。
3. **兩個系統的交會點**：FX 的幕 5／6 由機頭煞停判定，飛行的加速由航向對準判定；兩者在正常轉向下相差 1–3 tick，肉眼一致。

## 6. 繪製規格

材質全部 `AboveFog`（畫在迷霧 3175 之上，不受日夜影響）；排序值越大越上面。

| 元素 | 材質 | 尺寸 | 角度 | 排序 | 顏色／alpha |
|---|---|---|---|---|---|
| RCS 外焰 | `OuterA`（MoteGlow） | 寬 `1.25 × width`、長 `length` | 朝排氣方向 | 2.15 | `turnJetColor` |
| RCS 核心 | `Core` | 寬 `0.38 × width`、長 `0.8 × length` | 同上 | 2.18 | `coreColor` |

| 主焰外層 | `OuterA/B` 交替 | 寬 `width`、長 `1.8 × length` | 彈體 | 2.2 | `flame` |
| 主焰核心 | `Core` | 寬 `0.35 × width`、長 `length` | 彈體 | 2.4 | `coreColor` |
| 主焰光暈 | `Halo` | 直徑 `2.5 × width × thrust` | 0 | 2.3 | `flame` @ 0.6 |
| 轉向段 | `TurnPodFor(turnPodTexPath)`（Transparent） | `turnPodWidth × turnPodLength` | `podRot` | 2.1 | 白，alpha＝`(1 − age/100) × 4` 夾在 0–1 |
| 轉向段殘焰 | `OuterA` + `Core` | 1.1 格，前 24 tick 淡出 | `podRot` | 2.16 / 2.19 | `flameColor` |

主焰的 `length`＝`coreLength(3.52) × thrust × flicker × (1 + 0.3 × min(speed/3,1)) × effectScale × (1 + (mainPlumeScale − 1) × main)`；
`flicker`＝0.9–1.1（兩條正弦疊加，種子每枚彈固定），所以主推力全開時（`main = 1`、速度已達上限）主焰長約 6.2 格、寬約 1.8 格（外層 quad 再 ×1.8 長）。

## 8. 驗收

### 8.1 自動（BVRTests）

- `IsBraking` 正反例；`ThrustAt(mainBlend)` 的 0.5 → 0.57、1 → 1、燒完不復燃。
- Oniks def 真的指向 `DMSE_LaunchFx_Oniks`，且 profile 有 `turnJets`、`mainThrust`、`turnPodEjectSpeed`、`turnPodTexPath`。
- 目前 1857 checks 全綠。

### 8.2 實機（V9）

`AcceptanceDriver.Watch` 逐 tick 驗四個條件（不是固定 tick 截圖）：

| 條件 | 判定 |
|---|---|
| side | `TurnActive && TurnJetAim > 0 && |TurnRate| ≥ turnJetRate` |
| retro | `TurnActive && TurnJetAim > 0 && |TurnRate| < turnJetRate`（反推時方向相反） |
| jettison | `Jettisoned && PodAge ≥ 0` |
| main | `MainThrustBlend > 0.9` 且 `Thrust > 0.8` |

截圖：`oniks_side_thrust`（側推）、`oniks_pod_jettison`（拋棄）、`oniks_main_thrust`（主推力）、`oniks_arc`（拉遠看整條煙跡是不是乾淨的弧）。

## 9. 調參指南

| 想要 | 改什麼 | 副作用 |
|---|---|---|
| 點放更密 | `turnJetPulseGapTicks` 8 → 5 | 總長變短（6 × 8 ＝ 48 tick），可能還沒煞停就拋棄 |
| 點放更少／更快收 | `turnJetPulses` 6 → 4 | 大角度轉向會在還沒對準時拋棄 |
| 轉向更急 | `maxTurnRate` 2.6 → 4、`turnMaxAcceleration` 0.6 → 1 | 看起來更「彈」，煙跡弧半徑變小 |
| 火焰更大 | `turnJetLength` 2.4 → 3、`turnJetWidth` 0.8 → 1 | 貼圖小時會蓋住彈體 |
| 反推更明顯 | `turnJetBrakeScale` 0.75 → 1 | 反推火焰接近側推大小，幕 4 比較好看但較不「細膩」 |
| 主推力更誇張 | `mainPlumeScale` 1.3 → 1.6、`mainFlameColor` 更橘 | 尾焰會長到蓋住煙柱 |
| pod 飛更遠 | `turnPodEjectSpeed` 0.16 → 0.25 | 會離彈體太遠，看起來像另一枚彈 |

## 10. 已知限制

- 轉向推進器是**純視覺**：不存檔、不參與碰撞與傷害、不影響飛行；讀檔後視為已拋棄（不會補畫）。
- 遊戲內是熱射，沒有影片第 1 段的筒內彈射與筒口燃氣。
- pod 的物理是近似（直線減速＋自轉），不是真的剛體；它的存在只是為了幕 5 那一瞬間。
- 側推煙的顆數受 `LaunchFxBudget` 壓力限制：密度設定低時每 tick 可能只出一顆。
