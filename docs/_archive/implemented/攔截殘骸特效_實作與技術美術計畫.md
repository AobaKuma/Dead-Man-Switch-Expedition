# 攔截殘骸特效

版本：1.1｜定稿日期：2026-11-20｜狀態：第一版定稿

歸檔：2026-11-20，實作完成後移入 `_archive/implemented/`；本檔仍為現行規格參考。

適用：DMSE 1.7。實作狀態：**P0–P7 完成**（P0–P6 於 2026-10-26，實機 M5、I1–I8；遠距末端攔截 2026-10-27；P7 清理 2026-11-20）。原始完整計畫（含各階段過程紀錄）在 `docs/_archive/`。

P7 清理（2026-11-20）：`glowMat`／`Flash` 方形暫位符已在 P2 移除，本次查核程式碼、Def 與建置產物無殘留；`Trigger(map, cell, terminal, sound)` 相容入口保留。`docs/BVR_Missile_系統流程.md` 新增 A-8 攔截表現（爆散、主殘骸、細碎片、遠距、預算與音效）。驗證：DMSE 建置成功；BVRTests 1,921 項全數通過（0 失敗）。

目標：取代攔截成功時的橙色方塊暫位符——在來襲航線上空爆，碎片保有來襲動量、拖著煙跡從來襲方向那側墜落。世界層攔截（`WorldObject_Interceptor`）不在範圍內。

## 1. 架構與檔案

```
攔截成功（SAM 離場結算 / CIWS 整輪判定）
  └─ InterceptEventData.From(target, kind, aimCell, approach)   ← 必須在 RemoveTarget / Discard / SpawnDebris 之前
       └─ MapComponent_InterceptEffects.Trigger(map, data) → 回傳載屍殘骸預測落點
            ├─ 閃光、火球、煙團、火花（FxCanvas 自持 fleck，可畫在圖外）
            ├─ 細碎片（InterceptDebrisFlecks，純視覺）
            ├─ 主殘骸 InterceptDebrisChunk（Thing，存檔，落地有後果）
            └─ 音效＋WeatherEvent_MissileFlash（沿用，12 tick 節流）
```

目錄 `.source/DMSE/SkyFallerTurret/BVR/InterceptDebris/`：

| 類別 | 內容 |
|---|---|
| `InterceptEventData` | 方位、爆心、高度、種類、profile、`remote`；`Build` 不依賴 Map（可測），`headingOverride` 供開發指令 |
| `InterceptGeometry` | 純數學：方位、平均速度、攔截點、`DebrisState` 初速／積分／落地／剔除、`RemoteBurstGround`、`EdgeFade`、`DrawHidden`；`IncomingHeading` 與 `CompTerminalCIWS.CalculateAimCell` 共用 |
| `InterceptDebrisPhysics` | 物理參數預設（未分 profile） |
| `InterceptDebrisProfileDef` | 塊數、質量、斷裂彈體機率、細碎片、齊射精簡數、繼承倍率、火球、冷卻色、`majorTexPath` |
| `InterceptDebrisFlecks` | 細碎片容器：每片 = 原版 `FleckStatic`（只畫）＋`DebrisState` |
| `InterceptDebrisChunk` | 主殘骸：一般 `Thing`（不是 Projectile） |
| `InterceptFxBudget`、`InterceptFxMaterial(s)` | 預算；蓋過迷霧的材質 |

呼叫點：`Projectile_MissileLaunch`（中過程）、`InterceptProjectile`（舊 skyfaller 版）、`CompTerminalCIWS`（末端，傳 `lastAim`、`approach`）。舊 `Trigger(map, cell, terminal, sound)` 保留為相容入口。之後改畫在共用 `FxCanvas`（見[導彈發射特效](_archive/implemented/導彈發射特效_重製計畫.md)）。

Def：`1.7/Defs/Effects/DMSE_InterceptFx.xml`；貼圖由 `.source/Tools/gen_intercept_fx_textures.py` 以固定種子產生到 `1.7/Textures/Things/Effects/InterceptDebris/`（光暈、火花、煙團、火球、碎片、艙體板件、污漬）——改配方後重跑，不要手改輸出；手繪檔用同名覆蓋。

## 2. 引擎事實（rw17）

- `FleckManager.CreateFleck` 不檢查邊界但會覆寫 y；`FleckMaker.*` 才做 `ShouldSpawnMotesAt`。自持系統直接 `system.CreateFleck` 繞過兩者。
- `FleckThrown` 跨格出界即死，不能在圖外飛；`FleckStatic` 無邊界檢查。y 一律取 `def.altitudeLayer`＋`altitudeLayerIncOffset`，自填無效。
- `FleckStatic.Setup` 會呼叫 `Rand`：純視覺 fleck 必須包 `Rand.PushState(seed)`。`ageTicksOverride` 預設要給 -1。
- 原版 `FleckSystemBase<T>` 只從 `FleckCreationData` 建 fleck，帶不進高度與質量 → 改自持容器。
- `DynamicDrawManager` 依 `Position` 剔除、迷霧格不畫；`drawOffscreen = true` 跳過視野判斷。
- **地圖外畫不出來**：`MapEdgeClipDrawer`（MetaOverlay）蓋過所有 mote；鏡頭只能捲到邊緣外約 2 格。
- **Render queue**：Transparent 2900、Mote 3000、光照 3100、MoteGlow 3151、迷霧 3175、邊緣遮罩 4000。`InterceptFxMaterial` 把專屬材質設為 3176–3181（迷霧之上、邊緣遮罩之下）；主殘骸用 `InterceptFxMaterials.AboveFog` 複製材質。
- 原版 `Things/Mote/Smoke` 幾乎全透明。
- `Skyfaller.ticksToImpactMax` 不公開：空投艙平均速度用剩餘 `ticksToImpact`，否則 def 的 `ticksToImpactRange` 平均。

## 3. 攔截點

方位 `H`（0 = 北、順時針，慣例同 `MissileMapEntryUtility`）取自來襲物的 `EntryHeading`／`angle`，否則用離落點最遠的方向。顯示位置 = 地面點 + (0,0,h)。

- **中過程**：爆心畫面位置在入場邊緣**內側** `midcourseInset` 4–8 格（雲團越界部分被裁，看起來像在邊緣外擊落）。
- **末端**：CIWS 最後一發的掃射點 `lastAim`，高度 18→10 依 approach 內插；畫面位置離外框至少 `drawEdgeInset` 4 格。
- **遠距末端**（2026-10-27）：`approach < 0.2` 時爆心是入場邊緣外的虛擬點（沿航線外推 6–18 格 ×(1−approach/0.2)，上限 `ForwardTravel × remoteReach 0.6`，橫向 ±6）；南側入場再外推到畫面看不見。任何末端爆心畫面位置在圖外或離外框 < 4 格即為遠距：**不畫爆炸**，天空閃光 0.25；殘骸生成前先模擬（`BecomesVisible`），淡入不到 0.5 的不生成。`EdgeFade`：離外框 4 格內為 0，再往內 6 格漸變到 1；主殘骸改畫 Transparent 材質、影子用自有 `DrawShadow`。

## 4. 碎片運動

初速：`v = d_in·s_m·inherit + burst.xz`，`vh = −s_m·descentRatio + burst.y`；burst ∝ m^−0.35、向上偏 0.6；自轉 ∝ m^−0.5。斷裂彈體 inherit 取上限、burst ×0.3。每 tick：阻力 `k = dragBase·m^−0.5`、重力、風（`FxWind`）。調後 `descentRatio 0.1`、`gravity 0.006`：重殘骸自 14 格高平均 55–130 tick 落地。

## 5. 表現

- **爆散**：閃光、火球（貼圖自帶白→橙→暗紅）、四芒星火花、煙團；空投艙無火球；中過程 ×1.4。齊射 6 tick 內第 3 次起改精簡版。
- **主殘骸 `InterceptDebrisChunk`**：`DMSE_InterceptDebrisChunk`（Ethereal、`drawOffscreen`、`seeThroughFog`、不可選）；Position 固定在生成格（夾進圖內），畫面位置由 `DebrisState` 決定。存檔：彈道狀態、`hulk`、`sourceDef`、`drawScale`、`coolTicks`、`texPath`、`seen`。導彈 2–4 塊＋60% 斷裂彈體（畫來襲物貼圖 ×0.7），空投艙 2–3 塊＋50% 艙體。**不論玩家看哪張地圖都生成**。煙跡每 2 tick（斷裂彈體每 tick），熾熱期火光、前 60 tick 跡頭火花；只在當前地圖發射。
- **落地**：圖外安靜消失；屋頂只冒火花；水面水花；地面揚塵＋火花＋`DMSE_Filth_MetalScrap`（Graphic_Cluster，**texPath 必須是資料夾**）＋原版 `BulletImpact_Metal`（尚無自有音效）。
- **傷害**：`PlayerConfigSettings.interceptDebrisDamage`（預設關）：5–12 鈍傷（斷裂彈體 ×1.5），對象順序 pawn → edifice → 其他建築（否則會先打到牆下電線）。
- **細碎片**：導彈 14–24 片（0.2–0.6）、空投艙 8–14（0.4–1.0，繼承 ×0.6）、齊射 6 片；30 tick 由熾熱橙轉金屬灰；落地或圖外剔除。
- **Shader**：煙、火球、煙跡 Mote＋instancing（L1 後）；細碎片 Transparent；閃光、光暈、火花 MoteGlow。環境光見發射特效文件 `FxLighting`。
- **Profile**：`DMSE_InterceptDebris_Missile`、`DMSE_InterceptDebris_DropPod`（較重、冷灰、無火球）；`BVRTargetProps.debrisProfile` 可指定，否則依種類。
- **屍體空投**：`Trigger` 回傳載屍殘骸（斷裂彈體／艙體優先，否則最重）的無風彈道預測落點（也存 `LastDebrisLandingCell`）。`BVRTarget.SpawnDebris(map, debrisCell)` 在附近 6 格找可空投、不穿屋頂的格；找不到則沿殘骸落點→原落點每 6 格再找。攔截當下就生成（比殘骸落地早約 30 tick，可接受）。

## 6. 設定與預算

- `PlayerConfigSettings.interceptFxDensity` 低／中／高（倍率 0.4／1／1.5，低密度煙跡間隔加倍），與發射特效共用。
- 主殘骸嚴格上限 40（到上限不生成，屍體落點改用模擬殘骸預測）；細碎片 400（過半減半）；煙跡每圖每 tick 3／6／9 團。
- 驗收環境幀時間會漂移，P6 記錄的「齊射 +5 ms」不可靠；畫布繪製 CPU 約 0.6–0.7 ms。
